# LPPM Information System Web

Sistem Informasi LPPM (Lembaga Penelitian dan Pengabdian kepada Masyarakat) berbasis web yang dibangun untuk meningkatkan mutu dan kinerja penelitian serta pengabdian kepada masyarakat di institusi pendidikan.

## 📋 Deskripsi

Aplikasi web ini dirancang untuk memfasilitasi pengelolaan kegiatan penelitian dan pengabdian kepada masyarakat, termasuk:
- Manajemen proposal penelitian dan pengabdian
- Monitoring dan evaluasi kegiatan
- Pelaporan hasil penelitian
- Administrasi dan dokumentasi
- Dashboard analitik untuk pengambilan keputusan

## 🚀 Teknologi

Proyek ini dibangun dengan teknologi modern:

- **Frontend Framework**: Vite+React.js
- **Build Tool**: Vite
- **Language**: JavaScript
- **Styling**: TailwindCss
- **Development**: Hot Module Replacement (HMR)
- **Code Quality**: ESLint

## 📦 Instalasi

### Prasyarat

Pastikan Anda telah menginstall:
- [Node.js](https://nodejs.org/) (versi 16 atau lebih baru)
- npm atau yarn sebagai package manager

### Langkah Instalasi

1. **Clone repository**
   ```bash
   git clone https://github.com/lppm-sinus/lppm-information-system-web.git
   cd lppm-information-system-web
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Jalankan aplikasi dalam mode development**
   ```bash
   npm run dev
   ```
   ```yarn
   yarn dev
   ```
